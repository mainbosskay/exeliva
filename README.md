# Exeliva

Exeliva is a career growth and job application management platform designed to help users organize their job search, track applications, manage interviews, and monitor their career progress.

## Project Status

🚧 Under Development

## Vision

Exeliva aims to provide a simple and organized way for users to manage their job search and career growth from one platform.

## Planned Features

* User authentication
* Job application tracking
* Company management
* Interview tracking
* Resume management
* Follow up reminders
* Career analytics

## Technology

The backend will be built with Node.js, TypeScript, NestJS, PostgreSQL, and Prisma.

More features and technical documentation will be added as the project develops.
